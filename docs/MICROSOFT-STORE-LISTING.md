## Product name

FrameView Analyzer

## Description

FrameView Analyzer is a native Windows desktop application for analyzing and comparing NVIDIA FrameView captures and NVIDIA App performance-overlay logs.

Turn performance CSV data into an interactive benchmark workspace with synchronized charts, visible-range statistics, automatic capture filtering, and reusable benchmark metadata. Compare two runs with the Pair workflow or compare 2–8 captures as equal peers in Multi.

Inspect FPS, frame time, latency, GPU and CPU utilization, clocks, temperatures, power, and other telemetry when present in the source capture. Use GPU-active range detection, edge trimming, loading-screen and transition exclusion, zoom, pan, hover inspection, and range selection to focus on the part of a benchmark that actually matters.

Organize captures in a local Benchmark Library, add context such as game, resolution, graphics preset, upscaler, Frame Generation, Ray Tracing, driver version, tags, and notes, then export professional PNG reports with the benchmarks and metrics you choose.

FrameView Analyzer also supports Statistics CSV, benchmark JSON, and portable benchmark package exports. The application is local-first, has no telemetry, and makes no network calls during normal operation.

FrameView Analyzer is an independent open-source project and is not affiliated with or endorsed by NVIDIA Corporation.
