## Description

Frame Performance Analyzer is a native Windows desktop application for analyzing and comparing NVIDIA FrameView captures and NVIDIA App performance-overlay logs.

Turn performance CSV data into an interactive benchmark workspace with synchronized charts, visible-range statistics, automatic Precision filtering, and reusable benchmark metadata. Compare two runs with the Pair workflow or compare 2–8 captures as equal peers in Multi.

Inspect FPS, frame time, latency, GPU and CPU utilization, clocks, temperatures, power, and other telemetry when present in the source capture. Keep every recorded frame in Raw mode or enable Precision filtering to conservatively remove loading screens, transitions, FPS outliers, and capture edges. Use the compressed analyzed timeline, true per-frame points, zoom, pan, fixed cursor readouts, and range selection to investigate the part of a benchmark that actually matters.

Organize captures in a local Benchmark Library, choose Pair or Multi runs through the unified benchmark browser, and add custom benchmark names plus context such as game, resolution, graphics preset, upscaler, Frame Generation, Ray Tracing, driver version, tags, and notes. Export professional PNG reports with the benchmarks and metrics you choose.

Frame Performance Analyzer also supports Statistics CSV plus portable analyzed-data CSV and JSON exports that can be reopened later. The application is local-first, has no telemetry, and makes no network calls during normal operation.

Frame Performance Analyzer is an independent project and is not affiliated with or endorsed by NVIDIA Corporation.
