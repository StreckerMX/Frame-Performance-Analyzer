# Privacy Policy for Frame Performance Analyzer

**Effective date:** August 26, 2026  
**Publisher:** Strecker

Frame Performance Analyzer is a desktop application for analyzing and comparing NVIDIA FrameView benchmark capture files.

## Data handled by the application

Frame Performance Analyzer processes benchmark CSV files that the user explicitly selects. These files may contain performance and hardware telemetry generated by NVIDIA FrameView.

The application can also store optional benchmark metadata entered by the user, such as benchmark names, game or scene names, graphics settings, tags, and notes.

## Personal information

Frame Performance Analyzer does not intentionally collect personal information for advertising, profiling, analytics, or tracking. It does not require an account and does not transmit benchmark files, metadata, or analytics to the publisher or to third-party services.

The application may access file paths and other operating-system-provided information as part of normal local file operations. Unexpected error diagnostics stored locally by the application may contain operating-system or .NET-provided details such as file paths.

## Local storage

Application settings, optional benchmark metadata, library information, and diagnostic logs are stored locally on the user's Windows device.

Diagnostic logs are retained locally for a limited period and are not automatically uploaded or transmitted by Frame Performance Analyzer.

## Network communication

Frame Performance Analyzer does not include telemetry, advertising, analytics, cloud synchronization, or a remote logging service. Benchmark captures and user-entered metadata remain on the user's device unless the user independently chooses to export or share files outside the application.

## Data sharing

Frame Performance Analyzer does not sell, rent, or share user data with advertisers or other third parties. The application does not automatically send benchmark data or diagnostic logs to the publisher.

## User control and deletion

Users control which benchmark files are opened and which optional metadata is entered. Exported files are created only when the user requests an export.

Users can remove locally stored application data by deleting the relevant Frame Performance Analyzer data from their Windows user profile or by removing data through application features where available.

## Children

Frame Performance Analyzer is a general-purpose performance analysis utility and is not designed to collect personal information from children.

## Changes to this policy

This privacy policy may be updated when Frame Performance Analyzer's functionality or data practices change. The current version will be published in this repository.

## Contact and support

Questions about this privacy policy or Frame Performance Analyzer can be submitted through the public issue tracker for the Frame Performance Analyzer repository on GitHub.
